# ShopNow

## Description
An e-commerce platform built with Next.js, MongoDB, NextAuth, and Tailwind CSS, developed as a project for the Client-Side Web Development course.

## Installation
1. `git clone https://github.com/Anita592/ShopNow.git`
2. `npm install`
3. Create a `.env` file with `MONGODB_URI` and `NEXTAUTH_SECRET`
4. `npm run dev`
5. Open `localhost:3000/api/seed` to seed the database
